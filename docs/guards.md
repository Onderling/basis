# Guards — the designed-vs-built map

> Generated by `scripts/guard-index.mjs` (`npm run guard-index`). Do not edit by hand — a fitness test
> keeps it in sync with the actual guards. Live green/red: `node scripts/guard-index.mjs --status` or
> `npm run guards`.

Every guard is one machine-checked **design claim**. This index IS the map of what the system is
designed to be — a claim without a guard is exactly where the code silently drifts from the design.
